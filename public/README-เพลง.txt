วิธีเพิ่มเพลงพื้นหลังตอนทำแบบทดสอบ
=====================================

1. หาไฟล์เพลง mp3 ที่มีสิทธิ์ใช้งานได้ถูกกฎหมาย (ดูแหล่งแนะนำด้านล่าง)
2. เปลี่ยนชื่อไฟล์เป็น "bgm.mp3"
3. วางไฟล์ไว้ในโฟลเดอร์นี้ (public/) ทับตำแหน่งเดียวกับไฟล์นี้เลย
4. push โค้ดขึ้น GitHub ตามปกติ

แหล่งเพลง/เสียงฟรี ไม่มีปัญหาลิขสิทธิ์ (เช็คเงื่อนไขการใช้งานของแต่ละเว็บอีกครั้งก่อนใช้จริง):
- YouTube Audio Library (studio.youtube.com > Audio Library)
- Pixabay Music (pixabay.com/music)
- Free Music Archive (freemusicarchive.org)

แนะนำเลือกเพลงแนว lo-fi / instrumental เบาๆ ไม่มีเนื้อร้อง จะไม่รบกวนสมาธิเด็กตอนทำแบบทดสอบ
