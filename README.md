# flashcard-vocab — Phase 1

ระบบฝึกจำคำศัพท์วันละ 10 คำ (Next.js + Supabase)

## Phase 1 มีอะไรบ้าง
- โครง Next.js (App Router) พร้อมฟอนต์ Kanit และธีมสีตามโปรโตไทป์
- schema ฐานข้อมูล Supabase: `words`, `progress`, `app_state`
- ข้อมูลตัวอย่าง 60 คำ (6 วัน) พร้อม seed.sql
- หน้าแรกทดสอบการเชื่อมต่อฐานข้อมูล (แสดงจำนวนคำศัพท์ที่ดึงได้จริง)

## Phase 2 มีอะไรบ้าง
- หน้าแรก (`/`) กลายเป็น Dashboard จริง: วันที่ X/365, progress bar, streak, จำนวนคำที่จำได้/ต้องทบทวน (ดึงจาก Supabase จริง)
- หน้าเรียน (`/learn`): Flash Card ปัดซ้าย/ขวา, ปุ่มลูกศร, 🔊 อ่านออกเสียง, ❤️ จำได้ (บันทึกลงตาราง `progress`), ปุ่ม "ยังไม่ค่อยจำได้" (ส่งเข้าคิวทบทวน)
- ระบบคำนวณวันอัตโนมัติจาก `app_state.start_date` — ถ้าเกินจำนวนวันที่มีคำศัพท์ใหม่ในตาราง `words` จะเข้าสู่ "วันทบทวน" อัตโนมัติ โดยดึงคำจากสถานะ review/learned
- streak อัปเดตอัตโนมัติครั้งแรกที่เข้าเรียนของแต่ละวัน (นับต่อเนื่องถ้าวันก่อนหน้าเข้าเรียน, รีเซ็ตถ้าขาดช่วง)
- เมนู "แบบทดสอบ" และ "เล่นกับเพื่อน" เป็นหน้า preview (ยังไม่ทำงานจริง รอ Phase 3-4), ส่วน "คำที่ต้องทบทวน" ใช้งานได้จริงแล้ว (ดึงรายการจาก Supabase)

## Phase 3 มีอะไรบ้าง
- **ล็อคหน้าเรียน** — หน้า `/learn` ต้องกด ❤️ "จำได้" ให้ครบทุกคำก่อนถึงจะออกไปหน้าอื่นได้ (ปุ่มย้อนกลับล็อคไว้) คำที่กด "😕 ยังไม่ค่อยจำได้" จะถูกส่งไปต่อคิวด้านหลัง แล้ววนกลับมาให้ตอบใหม่เรื่อยๆ จนกว่าจะจำได้ครบทุกคำ
- **ป้ายระดับชั้น** — คอลัมน์ `grade_label` ในตาราง `words` (เช่น "ป.1") แสดงเป็นป้ายเล็กๆ มุมขวาบนการ์ด ไว้อ้างอิงเฉยๆ ไม่ใช่ตัวบังคับลำดับการเรียน คำศัพท์ยังคงเรียงจากง่ายไปยากต่อเนื่องกันตาม `day_index` เดิม ไม่ต้องเลือกระดับชั้นเริ่มต้น ทุกคนเริ่มจากคำแรกสุดเหมือนกัน
- **แบบทดสอบใช้งานได้จริงแล้ว** ที่ `/test` มี 3 รูปแบบ: ฟังแล้วพิมพ์, ดูความหมาย/รูปแล้วพิมพ์คำศัพท์ (ใหม่), เรียงตัวอักษร — ตอบถูก/ผิดจะอัปเดตสถานะคำในตาราง `progress` ทันที
- เพิ่มฟอนต์ **Sarabun** สำหรับคำอ่าน/คำแปลไทย (แยกจาก Kanit ที่ใช้กับคำศัพท์อังกฤษตัวใหญ่) อ่านง่ายขึ้น
- เพิ่มคอลัมน์ `image_url` ในตาราง `words` — ใส่ลิงก์รูปแล้ว Flash Card จะแสดงรูปด้านบนคำศัพท์อัตโนมัติ ไม่ใส่ก็แสดงแบบเดิมปกติ
- หน้า `/test`, `/play` เป็นหน้า preview บอกว่ากำลังจะมาใน Phase ถัดไป (กดจากเมนูหน้าแรกได้แล้ว)
- หน้า `/review` ใช้งานได้จริง แสดงรายการคำที่ต้องทบทวนพร้อมปุ่มฟังเสียง

## ขั้นตอนติดตั้ง

1. สร้างโปรเจค Supabase ใหม่ (ในบัญชี/องค์กรของลูก) ชื่อ `flashcard-vocab`
2. เปิด SQL Editor แล้วรันไฟล์ `supabase/schema.sql` ทั้งหมด
3. รันไฟล์ `supabase/seed.sql` เพื่อใส่คำศัพท์ตัวอย่าง 60 คำ
4. ไปที่ Project Settings > API คัดลอกค่า Project URL และ anon public key
5. คัดลอกไฟล์ `.env.local.example` เป็น `.env.local` แล้วใส่ค่าจากข้อ 4
6. รัน `npm install`
7. รัน `npm run dev` แล้วเปิด http://localhost:3000 — ควรเห็นข้อความ "เชื่อมต่อฐานข้อมูลสำเร็จ" และ "มีคำศัพท์ในฐานข้อมูลทั้งหมด 60 คำ"

## เพิ่มคำศัพท์ใหม่ยังไง

คำศัพท์ทั้งหมดอยู่ใน**ฐานข้อมูล Supabase** (ตาราง `words`) ไม่ได้ฝังอยู่ในโค้ด ดังนั้นไม่ต้องแก้โค้ด/deploy ใหม่ เพิ่มได้ 3 ทาง:

1. **พิมพ์เองใน Supabase Table Editor** — เปิดโปรเจค Supabase > Table Editor > `words` > กด Insert row กรอก `id`, `en`, `read`, `mean`, `day_index` (และ `image_url` ถ้ามีรูป) เหมาะกับเพิ่มทีละไม่กี่คำ
2. **รัน SQL เอง** — เขียน insert statement คล้ายไฟล์ `supabase/seed.sql` แล้ววางรันใน SQL Editor เหมาะกับเพิ่มทีละหลายสิบ/ร้อยคำ
3. **ส่งไฟล์มาให้ช่วยแปลง** — ส่ง Excel/CSV รายการคำศัพท์ (คอลัมน์: คำอังกฤษ, คำอ่านไทย, ความหมายไทย) มาในแชท จะแปลงเป็น SQL insert (แบบเดียวกับที่ทำให้ 60 คำแรก) ให้คัดลอกไปรันได้เลย — วิธีนี้สะดวกสุดถ้ามีคำศัพท์เตรียมไว้เป็นชุดใหญ่ (เช่นชุด 3,000 คำ)

หมายเหตุ: `day_index` เป็นตัวกำหนดว่าคำนั้นจะไปโผล่วันไหน (คำที่ 1-10 = day_index 1, คำที่ 11-20 = day_index 2 ฯลฯ) ถ้าใส่คำศัพท์เกินจำนวนวันที่มี ระบบจะเข้าสู่ "วันทบทวน" อัตโนมัติตามที่อธิบายไว้ด้านบน

## รูปภาพประกอบคำศัพท์

ใช้คอลัมน์ `image_url` ในตาราง `words` ใส่ลิงก์รูปภาพ (เช่นอัปโหลดขึ้น Supabase Storage หรือโฮสต์ที่อื่นแล้วคัดลอกลิงก์มาใส่) คำไหนมีค่าในคอลัมน์นี้ Flash Card จะแสดงรูปด้านบนคำศัพท์อัตโนมัติ คำที่ไม่มีรูปจะแสดงแบบเดิมตามปกติ ไม่มีผลกระทบ

## Phase 4 มีอะไรบ้าง
- หน้า `/play` ใช้งานได้จริงแล้ว: เลือกชุดคำ (วันนี้ / คำที่เคยเรียน / สุ่มจากทั้งหมด) แล้วเริ่มเล่นได้ทันที
- ยกจอให้เพื่อนดูคำศัพท์+ความหมาย ผู้ถือโทรศัพท์กดปุ่ม 👁 ซ่อน/แสดงคำศัพท์ เพื่อไม่ให้ตัวเองเห็นคำตอบ
- เพื่อนบอกความหมาย ผู้เล่นสะกดคำศัพท์ปากเปล่า แล้วผู้ถือโทรศัพท์กดตัดสินเอง ✅ ถูก / ❌ ผิด
- จบรอบแสดงคะแนนรวม พร้อมปุ่มเล่นรอบใหม่
